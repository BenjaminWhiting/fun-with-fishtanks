How it's made

Every model is code, every file is checked before it reaches the printer, and the printer is driven over the local network. Here's the path from idea to plastic, and the lessons that shaped it.

  • OpenSCAD 2021.01
  • Bambu Studio CLI
  • Python
  • LAN mode

From idea to plastic

  • 1. ModelEach part is an OpenSCAD file with its sizes as settings at the top. Rendered mock-ups come first, then the printable split.
  • 2. Check for overhangsprintcheck.py slices the STL every 0.2 mm and compares each layer with the one below, reporting anything that would start in mid-air.
  • 3. Sliceslice.py runs Bambu Studio from the command line with presets that have no start or finish tune.
  • 4. Preflightpreflight.py checks the file is intact and sliced for the A1 mini, follows every move (arcs included) to make sure it stays inside the printer's range, and checks the material and that the printer is idle.
  • 5. Clear plateA frame from the printer's camera confirms the plate is empty before anything starts.
  • 6. Printbambu.py uploads the file and starts it over the local network.

The tools are in the tools folder, with setup notes in its README.

Lessons learned

  • Check every move, not just the partA file once carried another printer's start-up moves, reaching far past the 7-inch bed. Now preflight follows every move before a file is sent.
  • Find the cause before trying againAfter a start-up fault, a quick restart without anyone checking the printer sent the toolhead into the nozzle wiper. Now nothing restarts until the cause is found.
  • Thin parts climb on their ownKnee braces printed upside down grew as free-standing 45-degree sticks and snapped off. Anything that rises alone needs real thickness.
  • Test the fitLantern pegs with 0.15 mm of play came out loose. Small fit tests with several plays now come before big parts.
  • A slicer that hangsThe command-line slicer froze forever on a hidden warning dialog from a sound driver. The slicing script now clicks it away.
Designed in OpenSCAD, printed on a Bambu Lab A1 mini. Sources, STLs and print files are on GitHub. Sizes are in inches; the models themselves are in millimetres.
